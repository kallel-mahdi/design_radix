KEY RESEARCH FINDINGS
================================================================================

CONVERSION OPTIMIZATION
  • Multiple CTAs reduce conversions by 266% (use 1 primary per section)
  • Social proof near CTAs increases conversions 68%
  • Pages loading <3s have 32% higher conversion rates
  • Video demos increase page dwell time 50%

MOBILE-FIRST DESIGN
  • 80-83% of landing page traffic is mobile
  • Design single-column first, scale up for larger screens
  • Touch targets minimum 44x44px (Apple HIG standard)
  • Body text minimum 16px (prevents iOS auto-zoom)

COMPONENT PATTERNS THAT CONVERT
  • Hero section with product demo (shows, doesn't tell)
  • Bento grid layout for features (varied sizes create visual rhythm)
  • Social proof positioned near CTAs (testimonials, logos, metrics)
  • Clear CTA copy: "Action Verb + Outcome" (e.g., "Start Free Trial")

ANIMATIONS (2025-2026 TREND)
  • Purposeful, minimal motion (scroll reveals, micro-interactions)
  • Avoid: Parallax, spinning, looping, decorative animations
  • Timing: <200ms for micro, 300-400ms for entrance, 2-3s for storytelling
  • Always respect prefers-reduced-motion (accessibility)

TYPOGRAPHY & SPACING
  • Hero headline: 32-48px | Section: 24-28px | Body: 16px
  • Line length: 65-75 characters (reduces eye strain)
  • Line height: 1.5 for body, 1.3 for headlines
  • Spacing grid: gap-16 to gap-24 between sections, p-6 to p-8 card padding

COLOR PSYCHOLOGY (Research Tools)
  • Blue (primary): Trust, calm, scholarly
  • Teal (secondary): Confidence, momentum
  • Violet (tertiary): Curiosity, innovation
  • Neutral grays: Organization and balance
  • WCAG AA requirement: 4.5:1 contrast minimum (all text)

PREMIUM LANDING PAGE PATTERNS
  • Linear: Bold, pixel-perfect, dark theme, product visible immediately
  • Vercel: Minimal, sleek, performance-optimized, Tailwind + Next.js
  • Notion: Content-first, hierarchical, flexible layouts
  • Common: Clear typography hierarchy, generous whitespace, interactive elements

MAGIC UI & ACETERNITY UI PATTERNS
  • Bento grids: Feature showcase with visual hierarchy
  • Scroll-triggered reveals: Fade-in + slide-up animations
  • Micro-interactions: Hover effects on buttons, forms, cards
  • Spotlight/Mask effects: Draw attention, before/after reveals
  • Advantage: Copy-paste ready, pre-optimized, responsive by default

KEY METRICS & RULES (Quick Reference)
================================================================================

CONVERSIONS:
  • 1 primary CTA per section (multiple = -266% conversion)
  • Social proof near CTAs (+68% conversion)
  • Load <3s (+32% conversion rate)
  • Video demo (+50% dwell time)

ACCESSIBILITY (WCAG AA):
  • Text contrast: 4.5:1 minimum
  • UI components: 3:1 minimum
  • Focus indicators: 3:1 minimum
  • Test BOTH light and dark themes

TYPOGRAPHY:
  • Headlines: 32-48px (desktop), 28-32px (mobile)
  • Body text: 16px (minimum on all devices)
  • Line length: 65-75 characters
  • Line height: 1.5 body, 1.3 headlines

SPACING:
  • Section gaps: gap-16 to gap-24 (Tailwind)
  • Card padding: p-6 to p-8
  • Grid gaps: gap-4 to gap-6

MOBILE:
  • 80%+ of traffic is mobile
  • Design single column first
  • Touch targets 44x44px minimum
  • <2.5s load time on 4G

COLORS (Citable tokens):
  • Primary: --blue-9 (buttons)
  • Secondary: --teal-9, --violet-9
  • Text: --mauve-12 (never pure white)
  • Borders: --mauve-6, --blue-6
  • Tints: --blue-3, --mauve-3

ANIMATIONS:
  • Micro-interactions: <200ms
  • Entrance: 300-400ms
  • Scroll-triggered: 2-3s
  • Always respect prefers-reduced-motion
