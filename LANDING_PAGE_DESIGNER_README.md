## Key Statistics & Rules (For Quick Reference)

### Conversion Metrics
- Multiple CTAs → 266% conversion decrease
- Social proof near CTAs → 68% conversion increase
- Pages loading <3s → 32% higher conversion rate
- Personalized CTAs → Better conversion than generic
- Video demo → 50% increase in page dwell time

### Mobile-First
- 80-83% of landing page traffic is mobile
- Buttons: 44px minimum height
- Body text: 16px minimum
- Load time: <2.5 seconds on 4G

### Accessibility (WCAG AA)
- Body text: 4.5:1 contrast ratio minimum
- Large text: 3:1 contrast ratio minimum
- UI components: 3:1 contrast ratio minimum
- Focus indicators: 3:1 contrast ratio minimum

### Typography
- Hero headline: 32-48px
- Section headline: 24-28px
- Body text: 16px (web standard)
- Line length: 65-75 characters
- Line height: 1.5 for body, 1.3 for headlines

### Animation Timing
- Micro-interactions: <200ms (snappy)
- Hover effects: 150-200ms (natural)
- Entrance animations: 300-400ms (smooth)
- Scroll-triggered: 2-3 seconds (storytelling)

### Spacing (Tailwind Units)
- Section gaps: gap-16 to gap-24 (64-96px)
- Card padding: p-6 to p-8 (24-32px)
- Grid gaps: gap-4 to gap-6 (16-24px)

## Color Tokens (Citable System)

### Primary Accent
- **Bibliography**: --blue-9 (buttons, primary CTAs)
- Background: --sand-1 (light), --sand-1-dark (dark)
- Borders: --blue-6, --mauve-6
- Tints: --blue-3, --mauve-3

### Secondary Accents
- **Manuscripts**: --teal-9 (secondary CTAs)
- **Discovery**: --violet-9 (tertiary CTAs)

### Text Colors
- Light mode: --mauve-12, --slate-12
- Dark mode: --mauve-12 (warm off-white, never pure white)

### Never Use
- Hardcoded hex values (#FFFFFF, #000000, #3B82F6)
- RGB/RGBA values
- Tailwind arbitrary colors
