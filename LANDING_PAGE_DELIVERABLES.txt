📊 KEY STATISTICS

CONVERSION METRICS:
  • 1 CTA per section (multiple CTAs = -266% conversion)
  • Social proof near CTAs = +68% conversion
  • Load <3s = +32% conversion rate
  • Video demo = +50% dwell time
  • Personalized CTA = better than generic
  • Testimonials = 68% conversion increase

MOBILE-FIRST:
  • 80-83% of traffic is mobile
  • Design single-column first, scale up
  • Touch targets 44x44px minimum
  • Load time <2.5s on 4G critical

ACCESSIBILITY (WCAG AA):
  • Text: 4.5:1 contrast minimum
  • UI components: 3:1 contrast minimum
  • Focus indicators: 3:1 contrast minimum
  • Test both light AND dark themes

TYPOGRAPHY:
  • Headline: 32-48px desktop, 28-32px mobile
  • Body: 16px minimum (all devices)
  • Line length: 65-75 characters
  • Line height: 1.5 body, 1.3 headlines

ANIMATIONS:
  • Micro-interactions: <200ms
  • Entrance: 300-400ms
  • Scroll-triggered: 2-3s
  • Always respect prefers-reduced-motion
