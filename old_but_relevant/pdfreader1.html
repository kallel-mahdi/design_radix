BC-LSTM Demonstrates Long-Term Memory

lies on a fixed attention window, supporting only short-term memory, while LSTM's recurrent state enables LTM. DT performs well within context but fails for L > 90; BC-LSTM generalizes further, though performance degrades at long training lengths (600, 900). If evaluated only on shorter lengths, DT may appear stronger, masking its lack of LTM.

Thus, DT exhibits only STM, whereas BC-LSTM demonstrates LTM despite gradient challenges [43, 44]. Our framework prevents such misinterpretations, showing that DT is suited to STM tasks via attention, while BC-LSTM supports LTM through recurrence.

6 Conclusion

We propose a unified framework for classifying and evaluating memory in RL agents, grounded in neuroscience-inspired definitions of short- and long-term declarative memory. By introducing the concept of correlation horizon and formalizing memory-intensive environments, we enable precise evaluation of agent memory.

Option A: Tab-based Navigation (Zotero Pattern)

Browser-like tabs at top. "My Library" tab sits alongside PDF tabs. Click library tab to return instantly.

  • Familiar pattern (browsers, Zotero, VS Code)
  • Multiple PDFs can be open simultaneously
  • Always visible - zero cognitive load to find "back"
  • Easy to switch between PDFs
  • Takes ~80px vertical space (tabs + toolbar)
  • May feel heavy for single-PDF workflows
  • More complex to implement

Option B: Auto-hide Toolbar (Distraction-free)

Toolbar fades away for immersive reading. Hover near top edge to reveal. Inspired by WordPress distraction-free mode.

  • Maximum reading space - content first
  • Clean, modern, premium feel
  • Smooth fade animation
  • Tools available when needed
  • User must discover hover behavior
  • Back button hidden - may feel "trapped"
  • Needs ESC keyboard shortcut as fallback
  • Harder on touch devices

Option C: Minimal Fixed Header

Slim ~48px header with back arrow, PDF title, and icon-only action buttons. Common web/mobile pattern.

  • Back button always visible - clear escape
  • Minimal vertical space (~48px)
  • Instantly familiar web pattern
  • Room for essential tools
  • Easy to implement
  • Single PDF at a time (no tabs)
  • Less feature-rich toolbar
  • Tools hidden behind icons/menu

Option D: Breadcrumb Navigation

Hierarchical path: Library › Collection › PDF. Click any level to navigate directly there.

  • Shows context - where PDF lives in hierarchy
  • Jump directly to collection (not just library)
  • Familiar file manager pattern
  • Good for deep collection structures
  • Path gets long for nested collections
  • Takes horizontal space
  • Can feel "enterprise-y" / less elegant
  • Redundant if collections aren't deep

Option E: Floating Action Button

No header. Floating "Back to Library" button in bottom-left corner. Maximum immersion, mobile-inspired.

  • Maximum reading space - truly fullscreen
  • Back button prominent and always visible
  • Modern, mobile-inspired aesthetic
  • Clean and minimal
  • No toolbar visible - where do tools go?
  • FAB may overlap content at some zoom levels
  • Unconventional for desktop apps
  • Need separate solution for PDF tools
